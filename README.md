# 🇵🇰 QistRisk AI — Credit Assessment Engine

AI-powered credit scoring & risk assessment engine built for Pakistan's fintech and micro-financing landscape.

## 🚀 Overview
QistRisk AI evaluates applicant creditworthiness using machine learning models trained on credit parameters, including **eCIB scores**, monthly income, debt-to-income (DTI) ratios, and tenure.

## ✨ Features
* **eCIB Risk Profiling:** Integrates simulated SBP eCIB score benchmarks.
* **Instant ML Decisioning:** Logistic Regression model for instant approval/rejection probabilities.
* **Interactive Parameters:** Live input controls for applicant income, existing debts, and requested financing.
* **Biometric & Document Placeholders:** Built-in indicators for NADRA Verisys and auto-parsed bank statements.

## 🛠️ Tech Stack
* **Language:** Python
* **UI Framework:** Streamlit
* **Machine Learning:** Scikit-Learn (Logistic Regression, StandardScaler)
* **Data Processing:** Pandas, NumPy
